How to Install Humanize

1

Download the Extension

Click below to download the official Humanize extension ZIP file to your computer.

Download .zip
2

Open Extensions Page

In Chrome, type chrome://extensions in your URL bar and hit Enter.

3

Enable Developer Mode

Toggle the "Developer mode" switch in the top right corner of the extensions page to ON.

4

Drag and Drop

Simply drag and drop the downloaded humanize-extension.zip file anywhere onto the extensions page to install it!
